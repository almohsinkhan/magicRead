# MagicRead 
Through this project i will try to make a pdf reader that 
can be contolled by hand Gesture 
it going to support feature that can done using like
- Zoom in and out 
- scroll up and down
- highlight word or sentence 
- finding word meaning 

## module we are using 
opencv - python : for webcam +  image processing 
mediapipe :  Hand/hand-landmark tracking 
numpy :  Numerical operations
pymupdf : Read/render PDF + exract text
pillow : Image handling
requests : Dictionary/API requests later 
matplotlib : Debugging/visualizing coordinates


## Milestones 
milestone 1 : Webcam + hand Tracking
milestone 2 : gesture Recognition
milestone 3 : PDF Viewer
milestone 4 : Connect Gestures -> PDF viewer 
milestone 5 : Virtual Cursor
