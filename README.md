# MagicRead 📖🖐️

**MagicRead** is a gesture-controlled PDF reader that lets you interact with documents using hand gestures through a webcam.

The goal is to make reading and navigating PDFs more natural by reducing the need for a mouse and keyboard.

## ✨ Features

* 🔍 Zoom in and out
* 📜 Scroll up and down
* 🖊️ Highlight words or sentences
* 📖 Find word meanings
* 🖱️ Virtual cursor
* 🖐️ Hand gesture-based interaction

## 🎮 Controls

* 🖐️ Swipe an open palm left or right to change pages.
* 🤏 Move a pinched hand up or down to scroll.
* 👐 Move two hands apart or together to zoom in or out.

## 🛠️ Tech Stack

* **OpenCV** — Webcam input and image processing
* **MediaPipe** — Hand landmark detection and tracking
* **NumPy** — Numerical operations
* **PyMuPDF** — PDF rendering and text extraction
* **Pillow** — Image processing
* **Requests** — Dictionary/API requests
* **Matplotlib** — Debugging and coordinate visualization
